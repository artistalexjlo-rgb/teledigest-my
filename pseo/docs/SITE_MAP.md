# Как устроен сайт — словами

Описание СОСТОЯНИЯ НА 2026-08-14, без кода. Порядок: сверху вниз по дереву.
Ниже у каждой страницы четыре поля: **что это · откуда содержимое · что на ней видно ·
чем ограничена**. Если поле начинается с ⚠️ — это известная слабость, а не описание.

Дерево целиком:

```text
/<язык>/                                  главная: список стран
  /<язык>/<страна>/                       ХАБ страны: плитки разделов
    /<язык>/<страна>/s/<раздел>/          РАЗДЕЛ: плитки разборов + свой хвост
      /<язык>/<страна>/<разбор>/          РАЗБОР: короткий ответ + абзацы из чатов
        /<язык>/<страна>/<разбор>/<ветка>/  ВЕТКА: часть крупного разбора
служебные (не контент, в карту сайта не идут):
  /<язык>/go/luky/                        шлюз клика в продукт
  /<язык>/find/                           поиск по заголовкам
  /<язык>/about/                          о проекте
```

Языков 14. Адреса ниже страны одинаковы во всех языках (латинский хвост), поэтому
переключатель языка ведёт на ту же страницу.

---

## 1. Главная `/<язык>/`

- **Что это.** Вход в язык: поиск по странам, «популярные», страны по регионам.
- **Откуда содержимое.** Список стран, у которых собралась хотя бы одна страница;
  ранжирование «популярных» — по числу разборов страны.
- **Что видно.** Поле поиска по названиям стран, плитки популярных стран,
  аккордеон регионов (8 регионов, 249 стран из справочника).
- **Граница.** Страна без ни одной собранной страницы не показывается нигде —
  ни здесь, ни в переключателе, ни в карте сайта.

## 2. Хаб страны `/<язык>/<страна>/`

- **Что это.** Вход в страну. Список её РАЗДЕЛОВ, не список страниц.
- **Откуда содержимое.** Разделы берутся из разборов страны: у каждого разбора есть
  раздел, проставленный ртом `assign` (закрытый список из 13 разделов).
- **Что видно.** До 13 плиток разделов со счётчиком советов; плитка — ссылка на страницу
  раздела. Плюс два мостика (вопросы, разделы) и отдельные карточки для разборов,
  которым раздел не достался.
- **Граница.** Раздел получает плитку только если у него в этой стране ЕСТЬ своя
  страница. Замер: таких пар «страна × раздел» без страницы 12 из 249, за ними 23 разбора —
  они остаются карточками.
- ⚠️ **Слабость.** Группировка работает только там, где у раздела есть имя на этом языке.
  У 13 языков корпус ещё на старом наборе разделов, поэтому там хаб пока плоский —
  выправится после прогона переводов.

## 3. Страница раздела `/<язык>/<страна>/s/<раздел>/`

- **Что это.** Раздел страны: «Визы» в Греции, «Транспорт» в Бразилии.
- **Откуда содержимое.** Две разные вещи на одной странице: сверху РАЗБОРЫ этого раздела
  (страницы-ответы), ниже ХВОСТ — заметки, которые в разбор не собрались, разложенные по
  разделам ртом `assign`.
- **Что видно.** Плитки разборов со счётчиком, под ними заметки хвоста (у каждой тип:
  регламент, лайфхак, инструкция, риск, кейс, сервис).
- **Граница.** Страница строится, если у раздела в этой стране не меньше трёх заметок
  хвоста. Разборы сами по себе страницу раздела не создают.
- ⚠️ **Слабость.** Разборов в разделе бывает 41 при девяти настоящих сюжетах — раздел
  выходит длинным списком почти одинаковых заголовков. Лечится укрупнением (не сделано).

## 4. Разбор `/<язык>/<страна>/<разбор>/`

- **Что это.** Одно узкое дело: «Сроки оформления шенгенской визы в Грецию».
- **Откуда содержимое.** Мухи (готовые советы из чатов) → рот `facet` переводит и
  размечает → рот `carve` режет плотную пачку на узкие дела → дедуп схлопывает
  повторы в группы → рот `kratko` пишет короткий ответ.
- **Что видно.** Короткий ответ сверху, ниже 4–27 абзацев чужого опыта; у каждого
  счётчик «✓ N из чатов» — сколько независимых голосов это подтвердили.
- **Граница.** Страницей становится дело от 4 абзацев. Меньше — уходит в хвост раздела.
  Метка-заголовок обязана быть одним запросом: сборные («Прочее», «Общие советы»,
  имя раздела) страницей не становятся, их абзацы уезжают в хвост раздела.

## 5. Ветка `/<язык>/<страна>/<разбор>/<ветка>/`

- **Что это.** Часть слишком большого разбора.
- **Откуда содержимое.** Если у разбора больше 15 групп, рот делит его на под-темы.
- **Что видно.** То же, что у разбора, но по одной под-теме; на самом разборе тогда
  плитки веток и остаток аккордеоном.
- **Граница.** Порог 15 групп. Замер: крупных разборов 79, из них разветвлено 71,
  простынями остались 8.

## 6. Шлюз клика `/<язык>/go/luky/`

- **Что это.** Не контент, а счётчик: через него идут ВСЕ двери в продукт.
- **Откуда содержимое.** Ничего своего: пересылает в Luky.
- **Что видно.** Одна кнопка (для тех, у кого скрипты выключены), дальше сразу переход.
- **Граница.** Помечен `noindex`, в карту сайта не идёт. Считаем по логу веб-сервера:
  в адресе стоят страна и раздел, значит видно, что именно отдаёт переходы.

## 7. Поиск `/<язык>/find/`

- **Что это.** Поиск по заголовкам плюс прибор замера: что люди спрашивают.
- **Откуда содержимое.** Один файл на язык со всеми заголовками собранных страниц;
  строится рендером из того, что реально отрендерилось. Русский: 3 124 заголовка, 77 КБ в gzip.
- **Что видно.** Поле (оно же на всех страницах сайта), список найденных заголовков.
- **Граница.** Только по заголовкам, не по текстам; смысловой поиск — отдельная работа.
  Запрос попадает в лог веб-сервера, потому что уходит адресом `?s=…`.

## Что делает рот, а что код (важно для проверки выводов)

| работа | кто | ключи |
|---|---|---|
| перевод и разметка мухи | рот `facet` | да |
| нарезка на узкие дела | рот `carve` | да |
| раздел разбору и раскладка хвоста | рот `assign` | да |
| короткий ответ страницы | рот `kratko` | да |
| перевод на 13 языков | рот `translate` | да |
| схлопывание повторов в группы | код (векторы bge) | нет |
| адреса, плитки, поиск, шлюз, счётчики | код | нет |
| отсев сборных меток и пустых стран | код | нет |

## Чего в этой схеме ещё НЕТ

- **Публикация.** Всё выше — про то, что СОБИРАЕТСЯ. На сайте лежит дерево от 9 августа:
  902 разбора против 1 889 собираемых, 119 страниц разделов против 425, веток ноль.
  Кнопки публикации в пульте нет — сборка запускается с десктопа ассистента.
- **Укрупнение и переезд адресов.** Решено делать одной миграцией до публикации.
